## Selected work

### Lerna AI — learning from study materials

Co-built with [Caleb Kale](https://calebships.com). A study workspace for asking questions about uploaded materials and continuing saved tutoring conversations.

The architecture uses Gemini for tutoring, Supabase for authentication, and Elasticsearch for conversational memory. The project continues to evolve; this summary focuses on document-based tutoring and saved sessions.

**Stack:** Next.js, TypeScript, Supabase, Gemini, Elasticsearch.

[Lerna source](https://github.com/raymondstudio/Lerna) · [Lerna demo](https://uselerna.app)

### Sentria — security-report triage prototype

My prototype for turning unstructured security reports into incident categories, severity, technical indicators and related-report groups. A structured incident representation feeds the priority queue and correlation views.

The project explores AI-assisted classification and privacy-aware redaction. These remain prototype capabilities, rather than verified production security guarantees.

**Stack:** Next.js, TypeScript, Gemini, Zod.

[Sentria source](https://github.com/raymondstudio/sentria) · [Sentria demo](https://sentria-app.vercel.app)

### Atrixia — team shopping-agent prototype

A team hackathon project, with the canonical repository under [Ozomata-Emmanuel](https://github.com/Ozomata-Emmanuel). I worked on this with the Atrixia team.

The team architecture normalizes marketplace listings behind adapters, stores searches and conversations in PostgreSQL, and streams progress through Server-Sent Events. It helps compare product trade-offs; marketplace availability and data quality remain limitations. Checkout and image-to-marketplace search are outside the current implemented scope described in the project README.

**Stack:** React, Node.js, Express, TypeScript, PostgreSQL.

[Atrixia team source](https://github.com/Ozomata-Emmanuel/Atrixia) · [Atrixia demo](https://atrixia-ai.vercel.app)
